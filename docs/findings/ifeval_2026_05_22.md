The comparison is "our V4-Pro NVFP4 vs the closest publicly-shipped NVFP4 artifact in the DSV4 family.")

## Setup

- Hardware: 8× B300 SXM6 AC
- vLLM mainline @ `39910f2b25` + 4 patches
- Serve config: `--tensor-parallel-size 8 --enable-expert-parallel --moe-backend flashinfer_trtllm --attention_config.use_fp4_indexer_cache=True --compilation-config '{"cudagraph_mode":"FULL_AND_PIECEWISE","custom_ops":["all"]}'`, max-model-len 131072
- Eval: `lm-eval 0.4.12` via `local-chat-completions`, `num_concurrent=16`, `apply_chat_template=True`, `num_fewshot=0` (IFEval is zero-shot)
- MTP off

## Caveats

- `langdetect` Python package required for the IFEval task; without it the entire lm-eval task registry fails to load. Installed pre-run as part of `pip install langdetect immutabledict`.
- `--apply_chat_template=True` matches V4-Flash's run for like-for-like comparison.

Raw results: `docs/benchmarks/matrix/ifeval/`.

## Reproduction

```bash
# With serve up at port 8089 (see docs/QUICKSTART.md):
pip install langdetect immutabledict
lm-eval run \
  --model local-chat-completions \
  --tasks ifeval \
  --model_args "model=canada-quant/DeepSeek-V4-Pro-NVFP4-FP8-MTP,base_url=http://localhost:8089/v1/chat/completions,num_concurrent=16,max_retries=3,tokenized_requests=False" \
  --batch_size 1 \
  --apply_chat_template \
  --output_path ifeval_results
```
